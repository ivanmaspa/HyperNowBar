# HyperNowBar 1.G.2

![Release](https://img.shields.io/badge/release-1.G.2-brightgreen)
![Android](https://img.shields.io/badge/Android-12%20--%2016-blue)
![Framework](https://img.shields.io/badge/Xposed-Vector%20%2F%20LSPosed-green)

**HyperNowBar** — универсальный standalone-модуль для **Vector / LSPosed**, добавляющий на экран блокировки Android 12–16 нижнюю динамическую капсулу в стиле **Samsung One UI 7 Now Bar**, **ColorOS Fluid Glass** и **iOS Stacked Notifications / Liquid Glass**.

Подходит для **любых марок и прошивок**: Xiaomi (HyperOS / MIUI), Samsung (One UI), Google Pixel / AOSP / LineageOS / EvolutionX / crDroid, OnePlus / OPPO / Realme (ColorOS / OxygenOS / Realme UI), Nothing OS, Vivo (OriginOS) и др.

## Ключевые возможности `1.G.2`
- **Автоадаптация под любые телефоны, экраны и сканеры отпечатков:**
  - Автоматически определяет наличие подэкранного сканера (оптического / ультразвукового UDFPS) и его реальную высоту на экране — капсула и открытое меню всегда располагаются аккуратно **над** сканером.
  - На телефонах **без подэкранного отпечатка** (боковой/задний сканер или без отпечатка) капсула автоматически опускается **комфортно вниз** к нижнему краю экрана.
  - Адаптивная ширина под узкие экраны, стандартные смартфоны и складные устройства/планшеты + возможность ручной подстройки высоты в любой момент.
- **Скрытие иконки с рабочего стола:**
  - Переключатель **«Скрыть иконку с рабочего стола»** убирает ярлык из лаунчера, а настройки модуля всегда открываются кнопкой внутри **Vector / LSPosed**.
- **Единая нижняя капсула + раскрываемое меню:**
  - **Умный плеер с мульти-переключателем:** обложка, исполнитель, интерактивная перемотка, быстрые кнопки `Play/Pause + Next` прямо на капсуле, переход в приложение с запросом разблокировки, а при открытии 2+ музыкальных приложений (например, Яндекс Музыка + Spotify) автоматически появляется кнопка `⇄ 1/2`.
  - **Листаемая 3D-стопка уведомлений (стиль iOS):** карточки накладываются друг на друга с глубиной и плавно перелистываются пальцем вверх/вниз с инерцией и пружинным доворотом.
  - **Настоящий аппаратный GPU-блюр под разные прошивки:** AOSP `SurfaceFlinger BackgroundBlurDrawable`, Xiaomi `HyperOS MiBackgroundBlur`, Samsung `One UI SemBlurInfo` + отдельная регулировка заднего блюра фона за открытым меню (`0..160 px`).
- **Компактный адаптивный режим (Бета):** уменьшенный плеер, компактная стопка карточек без внешней рамки меню и затемнения; сворачивается обратно в бар при выключении и включении экрана.
- **Гибкое управление уведомлениями:** источник (**Все из шторки** / **После выключения экрана**) + очистка после разблокировки (**Вкл / Выкл**).
- **Опциональный режим жидкого стекла iOS (Liquid Glass):** выключен по умолчанию.
- **Пресеты и настраиваемые анимации:** 7 встроенных пресетов + создание и удаление собственных пресетов, 4 профиля анимаций + скорость (`50..180%`), 8 акцентных цветов + автоцвет по обложке.
- **Чистый экран блокировки + крупные часы:** скрывает стоковый список уведомлений на экране блокировки и удерживает крупные часы (HyperOS 3 + AOSP/Pixel).

## Установка (через Vector / LSPosed)
1. Скачайте **`HyperNowBar-1.G.2.apk`** из раздела [Releases](../../releases) и установите как обычное приложение.
2. Откройте **Vector** или **LSPosed** → **Модули** → включите **HyperNowBar**.
3. В области применения выберите **только «Системный UI» (`com.android.systemui`)** *(включите «Показать системные приложения» в меню `⋮`)*.
4. Перезапустите `SystemUI` (кнопкой внизу приложения `HyperNowBar`) или перезагрузите телефон.

## Сборка из исходников
Модуль написан на чистой Java 11/17 без тяжелых зависимостей и собирается напрямую через `aapt2` + `javac` + `d8` + `apksigner` (см. [`build.ps1`](build.ps1)).
