# HyperNowBar 1.G.1

![Release](https://img.shields.io/badge/release-1.G.1-brightgreen)
![Platform](https://img.shields.io/badge/HyperOS-3%20(Android%2016)-blue)
![Framework](https://img.shields.io/badge/Xposed-Vector%20%2F%20LSPosed-green)

**HyperNowBar** — standalone-модуль для **Vector (LSPosed)**, который добавляет на экран блокировки HyperOS 3 нижнюю динамическую капсулу в стиле **Samsung One UI 7 Now Bar**, **ColorOS Fluid Glass** и **iOS Liquid Glass / Stacked Notifications** (протестировано на Xiaomi 13 `fuxi`, HyperOS 3 / Android 16).

## Ключевые возможности релиза 1.G.1
- **Единая нижняя капсула над сканером отпечатков:**
  - Показывает обложку, название трека, живой 4-полосный эквалайзер, быстрые кнопки **Play/Pause + Next** в 1 тап и счётчик входящих сообщений.
  - Позиция, ширина, скругление, толщина контура и размер шрифта настраиваются в реальном времени без перезагрузки `SystemUI`.
- **Раскрываемое меню (плеер + 3D-стопка уведомлений):**
  - **Умный плеер с мульти-переключателем:** обложка, исполнитель, интерактивная перемотка (`SeekBar`), переход в приложение с запросом разблокировки, а при открытии 2+ музыкальных приложений (например, Яндекс Музыка + Spotify) автоматически появляется кнопка переключения `⇄ 1/2`.
  - **Листаемая 3D-стопка уведомлений (стиль iOS):** карточки физически накладываются друг на друга с глубиной и плавно перелистываются пальцем с инерцией и пружинным доворотом.
  - **Красивый задний GPU-блюр фона:** аппаратное полноэкранное размытие обоев и часов за раскрытым меню (`HyperOS MiBackgroundBlur`) с отдельной регулировкой силы блюра (`0..160 px`) и затемнения.
- **Компактный адаптивный режим (Бета, переключаемый в настройках):**
  - Меньше плеер, компактнее карточки уведомлений, **без внешней рамки меню и затемнения** — виджеты парят адаптивно, занимая минимум места. Сворачиваются обратно в Now Bar после выключения и повторного включения экрана.
- **Гибкое управление уведомлениями:**
  - Выбор источника: **Все из системной шторки** или **Только новые после выключения экрана**.
  - Выбор очистки: **Очищать после разблокировки** или **Без очистки**.
- **Опциональный режим жидкого стекла iOS (Liquid Glass):**
  - Выключен по умолчанию; при включении добавляет стеклянные блики, ледяной кант и преломление как в iOS.
- **Пресеты и глубокая кастомизация:**
  - **7 встроенных пресетов** (`One UI 7`, `iOS Стекло`, `Ч/Б Город`, `Компакт (Бета)`, `ColorOS`, `OLED Мат`, `Неон Фрост`) + **создание, применение и удаление собственных пресетов**.
  - **Настраиваемые анимации:** 4 профиля (`Пружина iOS`, `HyperOS`, `Выезд`, `Мгновенно`) + ползунок скорости (`50..180%`) и тактильный отклик кнопок.
  - **4 базовых стиля + 8 акцентных цветов** + автоподбор цвета по обложке трека.
- **Чистый экран блокировки + всегда растянутые часы HyperOS 3:** скрывает стоковый `NotificationStackScrollLayout` и блокирует сжатие часов `KeyguardClockContainer` / `ClockBaseAnimation`.

## Установка (через Vector / LSPosed)
1. Скачайте **`HyperNowBar-1.G.1.apk`** из раздела [Releases](../../releases) и установите как обычное приложение.
2. Откройте **Vector** → **Модули** → включите **HyperNowBar**.
3. В списке приложений нажмите меню (`⋮`) → **Показать системные приложения** и выберите **только «Системный UI» (`com.android.systemui`)**.
4. Перезапустите `SystemUI` (кнопкой внизу приложения `HyperNowBar` или перезагрузите телефон).

## Сборка из исходников
Модуль написан на чистой Java 11/17 без тяжелых зависимостей и собирается напрямую через `aapt2` + `javac` + `d8` + `apksigner` (см. [`build.ps1`](build.ps1)).
