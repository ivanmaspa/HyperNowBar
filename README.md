# HyperNowBar (Beta)

![Status](https://img.shields.io/badge/status-beta-orange)

![Framework](https://img.shields.io/badge/Xposed-Vector%20%2F%20LSPosed-green)

> **⚠️ BETA-версия** — проект находится в активной разработке и тестируется на Xiaomi 13 (`fuxi`, HyperOS 3 / Android 16).

**HyperNowBar** — standalone-модуль для **Vector (LSPosed)**, который добавляет на экран блокировки HyperOS 3 нижнюю динамическую капсулу в стиле **Samsung One UI 7 Now Bar**, **ColorOS Fluid Glass** и **iOS Stacked Notifications**:

## Возможности
- **Единая нижняя капсула над сканером отпечатков:**
  - Показывает обложку, название трека, живой 4-полосный эквалайзер, быстрые кнопки **Play/Pause + Next** в 1 тап и счётчик входящих сообщений.
  - Позиция настраивается ползунками в реальном времени без перезагрузки `SystemUI`.
- **Раскрываемое меню по тапу (плеер + сообщения в одной карточке):**
  - **Полноценный плеер:** обложка, исполнитель, интерактивная перемотка (`SeekBar`), управление треками, переход в плеер с запросом разблокировки.
  - **Стопка уведомлений в стиле iOS:** карточки частично накладываются друг на друга с глубиной; свайп влево/вправо листает стопку, свайп вверх раскрывает полный скроллируемый список, свайп вниз в начале списка складывает обратно в стопку.
  - **Переход в чат/приложение** по нажатию с системным запросом пароля/отпечатка (`StatusBarKeyguardViewManager.dismissWithAction`).
- **Настоящий системный GPU-блюр HyperOS:** использует нативный `HyperOS MiBackgroundBlur` / `SurfaceFlinger BackgroundBlurDrawable` с настройкой радиуса размытия (`20..160 px`) и прозрачности стекла.
- **Чистый экран блокировки + растягивающиеся часы HyperOS 3:** скрывает стоковый `NotificationStackScrollLayout` на локскрине и сообщает контроллеру часов (`KeyguardClockContainer`), что стоковых уведомлений нет, позволяя часам растягиваться.
- **Умная очистка после разблокировки:** просмотренные сообщения пропадают из капсулы после разблокировки (оставаясь в системной шторке) до прихода новых.
- **Умное автоскрытие:** автоматически прячется на Always-On Display (защита OLED), при открытии Центра управления и при вводе PIN/графического ключа (с автовозвратом при отмене).
- **4 стиля оформления:** `One UI 7 Glow`, `ColorOS Fluid Glass`, `Minimal Matte`, `Ч/Б Моно` + живой интерактивный предпросмотр в приложении.

## Установка (через Vector / LSPosed)
1. Скачайте **`HyperNowBar-v2.3-beta.apk`** из раздела [Releases](../../releases) и установите как обычное приложение.
2. Откройте **Vector** → **Модули** → включите **HyperNowBar**.
3. В списке приложений нажмите меню (`⋮`) → **Показать системные приложения** и выберите **только «Системный UI» (`com.android.systemui`)**.
4. Перезапустите `SystemUI` (кнопкой внизу приложения `HyperNowBar` или перезагрузите телефон).

## Сборка из исходников
Модуль написан на чистой Java 11/17 без тяжелых зависимостей и собирается напрямую через `aapt2` + `javac` + `d8` + `apksigner` (см. [`build.ps1`](build.ps1)).
